# Haider Dawood Khan — Research Profile

A dependency-free, one-page portfolio built for GitHub Pages.

## Update the site

- Edit section copy and project entries in `index.html`.
- Adjust the visual system and responsive layouts in `styles.css`.
- Update navigation behavior in `script.js`.
- Replace `assets/resume.pdf` with the latest CV when it changes.
- Replace `assets/profile.jpg` to update the portrait and social preview image.

The page is plain HTML, CSS, and JavaScript, so GitHub Pages can serve it directly from the repository root.
